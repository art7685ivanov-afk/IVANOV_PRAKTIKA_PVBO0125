# Практическая работа 20. Работа с дженериками
Практическая работа №20 по дисциплине «[Программирование на языке Джава](https://online-edu.mirea.ru/course/view.php?id=4053)» (РТУ МИРЭА, ИИТ, 2-ой курс).

**Преподаватель**: Ермаков Сергей Романович, ermakov_s@mirea.ru, ermakov@sumirea.ru.

## Задания

| Папка | Задание |
| --- | --- |
| `opt1` | Обобщённый класс с тремя параметрами `T`, `V`, `K` |
| `opt2` | Тот же класс с геттерами и выводом имён классов |
| `opt3` | Ограничения типов: `T extends Comparable`, `V extends Animal & Serializable` |
| `opt4` | Обобщённый `MinMax` и класс `Calculator` с обобщёнными статическими методами |
| `opt5` | Обобщённый класс `Matrix` со сложением, вычитанием и умножением матриц |
