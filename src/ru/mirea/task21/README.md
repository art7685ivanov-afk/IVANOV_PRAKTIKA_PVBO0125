# Практическая работа 21. Стирание типов в Java
Практическая работа №21 по дисциплине «[Программирование на языке Джава](https://online-edu.mirea.ru/course/view.php?id=4053)» (РТУ МИРЭА, ИИТ, 2-ой курс).

**Преподаватель**: Ермаков Сергей Романович, ermakov_s@mirea.ru, ermakov@sumirea.ru.

## Задания

| Папка | Задание |
| --- | --- |
| `opt1` | Конвертация массива строк или чисел в список |
| `opt2` | Класс для хранения массива любых типов |
| `opt3` | Получение элемента массива по индексу |
| `opt4` | Сохранение содержимого каталога в список и вывод первых пяти элементов |
| `opt5` | Вспомогательные методы `newArrayList`, `newHashSet`, `newHashMap` |

## Запуск

* `ru.mirea.task21.opt1.Task21_1`;
* `ru.mirea.task21.opt2.Task21_2`;
* `ru.mirea.task21.opt3.Task21_3`;
* `ru.mirea.task21.opt4.Task21_4` — путь к каталогу можно передать аргументом, по умолчанию используется текущий каталог;
* `ru.mirea.task21.opt5.Task21_5`.
