# Практическая работа 18. Исключения и работа с ними в Java
Практическая работа №18 по дисциплине «[Программирование на языке Джава](https://online-edu.mirea.ru/course/view.php?id=4053)» (РТУ МИРЭА, ИИТ, 2-ой курс).

**Преподаватель**: Ермаков Сергей Романович, ermakov_s@mirea.ru, ermakov@sumirea.ru.

## Задания

| Папка | Задание |
| --- | --- |
| `opt1` | Деление на ноль, деление вещественных чисел, обработка `ArithmeticException` |
| `opt2` | Ввод числа, обработка `NumberFormatException` и `ArithmeticException` |
| `opt3` | Перехват общего исключения `Exception` |
| `opt4` | Обработка исключений с блоком `finally` |
| `opt5` | Генерация `NullPointerException` в методе `getDetails` |
| `opt6` | Обработка `NullPointerException` внутри `printMessage` |
| `opt7` | Проброс исключения через цепочку методов с помощью `throws` |
| `opt8` | Повторный ввод ключа при возникновении исключения |
