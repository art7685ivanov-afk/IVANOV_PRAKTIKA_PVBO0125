# Практическая работа 19. Создание пользовательских исключений
Практическая работа №19 по дисциплине «[Программирование на языке Джава](https://online-edu.mirea.ru/course/view.php?id=4053)» (РТУ МИРЭА, ИИТ, 2-ой курс).

**Преподаватель**: Ермаков Сергей Романович, ermakov_s@mirea.ru, ermakov@sumirea.ru.

## Задания

| Папка | Задание |
| --- | --- |
| `opt1` | Оформление онлайн-заказа с проверкой ИНН и собственным исключением `InvalidInnException` |
| `opt2` | `LabClass`: сортировка студентов по среднему баллу и поиск по ФИО с исключением `StudentNotFoundException` |

## Запуск

* `ru.mirea.task19.opt1.Task19_1` — ввести ФИО и ИНН (10 или 12 цифр);
* `ru.mirea.task19.opt2.Task19_2` — консольное меню добавления, вывода, сортировки и поиска студентов.
